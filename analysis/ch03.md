## 1. Sections and concepts

### 3.1 Thresholding (pp. 37–38)
- Ice is brighter than water → intensity thresholding of the grayscale image is the natural ice/water segmentation.
- Global (one T for the image) vs variable/local thresholding (T varies across the image).
- **Eq. (3.1)** `g(x,y) = 1 if f(x,y) > T else 0` — binarisation rule; strict `>` (matches MATLAB `im2bw`: `I > 255·level`).
- Coordinates: `x` = row, `y` = column (Ch2 convention).

### 3.1.1 Global thresholding (pp. 38–39)
- Bimodal histogram → put T in the valley (Fig 3.1 sketch, Fig 3.2: T = 125 chosen by eye → IC = 41.47 %).
- Drawbacks: noisy histograms with many local extrema, overlapping modes, image-to-image variability → need an automatic T.
- No `.m` file: the manual-threshold part of `separability.m` (`bw = I > k`, `IC = #/mn`) is the code form of Eq. (3.1).

### 3.1.1.1 Otsu thresholding (pp. 40–43)
- Otsu [114]: choose t maximising a discriminant criterion computed from the normalised histogram only.
- **Eq. (3.2)** `n = M·N = Σ n_i` — total pixel count from the histogram.
- **Eq. (3.3)** `p_i = n_i / n` — normalised histogram as a discrete pdf (Ch2 Eq. 2.8; `core.histogram.normalized_histogram`).
- **Eq. (3.4)** `P0(t) = Σ_{i≤t} p_i` — class C0 = levels [0..t] probability (cumulative sum).
- **Eq. (3.5)** `P1(t) = Σ_{i>t} p_i = 1 − P0(t)` — class C1 = levels [t+1..L−1] probability.
- **Eq. (3.6)** `m0(t) = (1/P0) Σ_{i≤t} i p_i` — mean of C0 (via Bayes, `P(C0|i)=1`).
- **Eq. (3.7)** `m1(t) = (1/P1) Σ_{i>t} i p_i` — mean of C1 (text typo: `P(i|C0)` should read `P(i|C1)`).
- **Eq. (3.8)** `m(t) = Σ_{i≤t} i p_i` — cumulative mean up to level t.
- **Eq. (3.9)** `mG = Σ_i i p_i` — global mean.
- **Eq. (3.10)** `P0 m0 + P1 m1 = mG`; **Eq. (3.11)** `P0 + P1 = 1` — consistency identities.
- **Eq. (3.12)** `σ0²(t) = (1/P0) Σ_{i≤t} (i−m0)² p_i`; **Eq. (3.13)** `σ1²(t)` likewise for C1 — class variances.
- **Eq. (3.14)** `λ = σB²/σW², κ = σG²/σW², η = σB²/σG²` — three equivalent discriminant criteria.
- **Eq. (3.15)** `σW²(t) = P0 σ0² + P1 σ1²` — within-class variance.
- **Eq. (3.16)** `σB²(t) = P0(m0−mG)² + P1(m1−mG)² = P0 P1 (m0−m1)² = (mG P0 − m(t))² / (P0(1−P0))` — between-class variance; the last form is what `separability.m` line 38 and MATLAB `otsuthresh` compute.
- **Eq. (3.17)** `σG² = Σ_i (i−mG)² p_i` — global variance (constant in t).
- **Eq. (3.18)** `σW² + σB² = σG²`; **Eq. (3.19)** `λ = η/(1−η), κ = 1/(1−η)` — the criteria are monotone in each other.
- **Eq. (3.20)** `η(t) = σB²(t)/σG²` — the criterion actually maximised (first-order statistics only).
- **Eq. (3.21)** `σB²(t*) = max_{0<t<L−1} σB²(t)` — exhaustive search over integer t; ties → average the tied t (MATLAB `mean(find(...))`).
- **Eq. (3.22)** `0 ≤ η(t*) ≤ 1` — separability measure; 0 for constant image, 1 for a two-valued image {0, L−1}.
- Fig 3.3: Otsu on Fig 3.2(a) → t = 108, IC = 42.14 %, η(108) = 0.9643 vs η(125) = 0.9620. Assumes bimodality; degrades for small objects [82].
- Code: `Otsu.m` (graythresh + im2bw), `separability.m` (η from the equations). MATLAB `[level, em] = graythresh(I)` returns `em` = η(t*) exactly (read from `otsuthresh.m`: `em = maxval / (Σ p i² − mu_t²)`).

### 3.1.2 Local thresholding (pp. 43–45)
- Global Otsu fails under uneven illumination (Fig 3.4(a): Fig 3.2(a) with an artificial illumination ramp; global t = 176, Fig 3.4(b)).
- Divide into sub-images, threshold each (Fig 3.4(c): 2×3 blocks; thresholds 92/132/177/98/126/176; block ICs 73.8472/20.9869/25.1055/86.496/21.2756/20.2267 %; overall IC 41.32 % ≈ 42.14 % of the clean image).
- No numbered equation; algorithm = `local_Otsu.m` (blocks `I(t1:t2, t3:t4)`, `graythresh` per block, `IC = Σ n_block / (r c)`). Requires `r/n_r` and `c/n_c` integer (else MATLAB indexing errors).

### 3.1.3 Multithresholding (pp. 44–46)
- **Eq. (3.23)** `g = g_k if f > T_{k−1}; g_{k−1} if T_{k−2} < f ≤ T_{k−1}; … ; g_1 if f ≤ T_1` — k-level quantisation by k−1 thresholds (= MATLAB `imquantize`: `index = 1 + Σ (A > T_i)`).
- **Eq. (3.24)** `σB² = Σ_{j=1..k} P_j (m_j − mG)²` — multi-class between-class variance.
- **Eq. (3.25)** `P_j = Σ_{i∈C_j} p_i`; **Eq. (3.26)** `m_j = (1/P_j) Σ_{i∈C_j} i p_i` — class probability and mean.
- **Eq. (3.27)** `σB²(t1*,…,t_{k−1}*) = max_{0<t1<…<t_{k−1}<L−1} σB²` — exhaustive maximisation (MATLAB `multithresh` does this only for N ≤ 2; N ≥ 3 uses `fminsearch`).
- **Eq. (3.28)** `η = σB²(t*)/σG²` — separability of the multi-class split (= `multithresh`'s second output `metric`).
- Fig 3.5: 3-level Otsu of Fig 3.2(a): thresholds 61 and 142; coverages black 54.86 %, gray 4.31 %, white 40.83 %.
- Code: `Otsu.m` second half (`multithresh(I, 2)`, `imquantize`, per-class coverage and mean intensity).

### 3.2 Clustering (pp. 46–48)
- Unsupervised grouping by a distance measure; Euclidean vs non-Euclidean distances.
- **Eq. (3.29)** Euclidean `‖a−b‖₂ = sqrt(Σ(a_i−b_i)²)`; **Eq. (3.30)** squared Euclidean `Σ(a_i−b_i)²`; **Eq. (3.31)** max-norm `max|a_i−b_i|`;
  **Eq. (3.32)** city-block `Σ|a_i−b_i|`; **Eq. (3.33)** cosine `aᵀb/(|a||b|)`; **Eq. (3.34)** Mahalanobis `sqrt((a−b)ᵀ S⁻¹ (a−b))`, S = covariance.
- 3.2.1: hierarchical (agglomerative / divisive) vs partition clustering; partition clustering preferred for image segmentation [66].
- Text only — no `.m` file (distances are 1-D absolute differences inside `kmeans.m`).

### 3.2.2 K-means clustering (pp. 48–52)
- **Eq. (3.35)** `J = Σ_{i=1..k} Σ_{j=1..n_i} ‖x_j^(i) − c_i‖²` — within-cluster sum of squared distances, the objective minimised.
- **Eq. (3.36)** `S_i = {x_p : ‖x_p − c_i‖² ≤ ‖x_p − c_j‖² ∀j}` — assignment step (nearest centroid).
- **Eq. (3.37)** `c_i = (1/n_i) Σ_j x_j^(i)` — update step (cluster mean); repeat until centroids unchanged (Step 4).
- J is non-increasing and bounded below → finite convergence to a local minimum; sensitive to k and to initial centroids (Fig 3.6 2-D toy example with random init); outliers distort clusters (Fig 3.8).
- Fig 3.7: k-means on Fig 3.2(a): k=2 → IC 42.79 %; k=3 → 53.52 / 5.16 / 41.32 %.
- Code: `kmeans.m` = the **authors' own 1-D histogram k-means** (not the Statistics Toolbox function it shadows): init `mu = (1:k)·m/(k+1)` ("equal division points", confirmed in §3.3 text), distance `|level − mu|` (Eq. 3.36 in 1-D), ties → lowest cluster index, update = histogram-weighted mean (Eq. 3.37), stop when `mu == oldmu` exactly. **Deterministic, no randomness.**

### 3.3 Experiment results and discussion (pp. 52–58)
- Three Ny-Ålesund images (May 2011 [185]) → Figs 3.9–3.11 (= `1.jpg`, `2.jpg`, `test.jpg`), Table 3.1 (Otsu 15.36/32.05/72.63 %, k-means 15.65/32.49/96.50 %).
- Otsu ≈ k-means (k=2) when ice is uniformly bright (images 1, 2) because both minimise within-class variance [87]; on image 3 Otsu misses "dark ice" (brash, slush, submerged) → 72.63 % vs 96.50 %.
- Three groups (multi-Otsu N=2 vs k-means k=3) on image 3: Fig 3.12, Table 3.2 (multi-Otsu 54.39/42.11/3.50 → IC 96.50 %; k-means 77.91/19.20/2.89 → IC 97.11 %), Table 3.3 mean intensities (multi-Otsu 218.1751/177.0690/63.8908; k-means 209,0405 [sic]/161.6657/53.8234). Correct IC assumed 96–97 %.
- k-means gives lower group means → detects more ice pixels; also faster (no variances). Both methods force ≥2 classes → fail at IC = 0 % or 100 % (special cases).
- Code: `Otsu.m`, `kmeans.m` on `test.jpg` (image 3); same scripts on `1.jpg`/`2.jpg` after renaming.

## 7. Risks & questions

1. **`kmeans.m` units bug** (shifted centroids vs unshifted image, lines 64–70): all book k-means numbers depend on it. Decision recorded here:
   library default = correct Eqs. 3.36–3.37; `shift_bug=True` reproduces the script and the book; both reported side by side. The correct
   k=2 result on image 3 differs from the book's 96.50 % — must be stated, not hidden.
2. **Stale-buffer bug** (`s`/`ss` never cleared) in `Otsu.m` and `kmeans.m` mean-intensity loops: invisible on `test.jpg` (class sizes increasing),
   visible on `1.jpg`/`2.jpg`. Library computes true means; parity test emulates the stale sum for those refs and documents it.
3. **`separability.m` off-by-one**: η evaluated with C0 = levels 0..k−1 (t = 107) while the mask uses `I > 108`. Port the script faithfully in
   the wrapper, expose the book-convention `separability(gray, t)` separately; both refs (k = 107, 108) generated to prove which one MATLAB computes.
4. **Missing images `ch3ice.jpg` (Fig 3.2a) and `t.jpg` (Fig 3.4a)**: Figs 3.2–3.5 and 3.7 numbers cannot be reproduced; `2.jpg` substitute and a
   synthetic illumination ramp are used with explicit labels. Not obtainable from any tier (paper figure). Confirm with the user that this is acceptable.
5. **`multithresh` single-precision normalisation** (`single(A−minA)/single(maxA−minA)` → `grayto8`): bin edges may flip for values exactly at .5
   after the ×255 rounding; float32 emulation in numpy should match, else label `near`. The `grayto8` builtin's internal arithmetic (single vs double
   product) is not visible in `.m` source — verify on the `minA=5, maxA=250` ramp reference. N ≥ 3 uses `fminsearch` in MATLAB (local search,
   `TolX=1`) — exhaustive Eq. 3.27 for N=3 may legitimately find a better maximum → `reimplemented`, never `exact`.
6. **`graythresh` tie averaging** gives non-integer thresholds (e.g. 107.5) — `im2bw` then uses `I > 107.5`; keep float levels end-to-end (no rounding).
7. **Empty cluster in `kmeans_gray`** → MATLAB loops forever (NaN never equals NaN). Port raises `RuntimeError` after `max_iter` or on NaN; document as a deviation.
8. **Floating-point stop rule**: `mu == oldmu` exact equality; numpy's pairwise summation vs MATLAB's sequential `sum` could differ at 1e-13 and change
   the iteration count in pathological cases (not on the three images: 2/4/4 and 7/8/10 iterations converge cleanly). Use `math.fsum`-free plain
   `np.sum` and compare `n_iter` with the MATLAB ref (save a counter in the patched script).
9. **`colormap('default')`** after `imshow(mask1)` makes MATLAB display the k-means mask in parula; book figure is gray (from the paper) → save gray,
   note in the report.
10. **Later-chapter dependencies**: ch6/ch7/ch9 call the *Statistics Toolbox* `kmeans(ima, k, 'EmptyAction','singleton')` (k-means++, random) — a
    different algorithm from `kmeans.m`; that mapping (`sklearn.cluster.KMeans`, `approx`) is decided in ch6, but `core.clustering` should leave room
    for it (`kmeans_lloyd` with `init='kmeans++'` optional). ch9 `block_threshold.m` = `local_Otsu.m` → `block_otsu` must accept arbitrary `n_r, n_c`.
11. **Public substitutes at 4290×2856**: NASA Worldview snapshot size limits unknown at this resolution; three distinct scenes needed (one per file name).
    Check with real requests in the PUBLISH phase; if capped, choose dimensions divisible by 2 (rows) and 3 (cols).
12. **Inventory gaps**: `analysis/_matlab_inventory.md` lists neither `multithresh`/`imquantize` (Otsu.m) nor `colormap` (kmeans.m) as toolbox calls — the
    watchlist should be extended so ch7/ch8 inventories catch `multithresh`.
13. Text typos to be reflected in docstrings, not "fixed" silently: Eq. 3.7 `P(i|C0)` → `P(i|C1)`; Table 3.3 "209,0405" → 209.0405; Fig 3.4(c) `IC=86.496%`
    (`num2str` 4-significant-digit default).
