## 1. Sections and concepts

### 4.1 Derivative edge detection — intro (p. 59)
- Edges = rapid brightness change between neighbouring pixels; two criteria: large first derivative (gradient) or zero-crossing of the second derivative (Laplacian).
- Floe boundaries → feature extraction (area, perimeter, shape) and floe size distribution; motivation for Ch5+ (edges alone cannot separate touching floes, §4.3).

### 4.1.1 Gradient operator (pp. 59–63)
- **Eq. (4.1)** `∇f = [Gx, Gy]ᵀ = [∂f/∂x, ∂f/∂y]ᵀ` — gradient vector (book: `x` = row, `y` = column, Ch2 convention).
- **Eq. (4.2)** `|∇f| = sqrt(Gx² + Gy²)` — gradient magnitude.
- **Eq. (4.3)** `θ = arctan(Gx/Gy)` as printed ("with respect to the x-axis", quadrant-correct `arctan` = `atan2`) — gradient direction; the printed ratio is Gx/Gy (a standard text has Gy/Gx) → implement `atan2` with a documented argument order (risk 10).
- **Eq. (4.4)** `∇f ≈ Gx² + Gy²` — squared-magnitude approximation (what MATLAB `edge` thresholds internally: `b = bx² + by²`, `cutoff = T²`).
- **Eq. (4.5)** `∇f ≈ |Gx| + |Gy|` — absolute-magnitude approximation.
- **Eq. (4.6a)** `∂f/∂x ≈ f(x+1,y) − f(x,y)`; **Eq. (4.6b)** `∂f/∂y ≈ f(x,y+1) − f(x,y)` — running differences (Fig 4.1: 1-D kernels `[-1 1]ᵀ`, `[-1 1]`), located at half-pixel positions → motivates symmetric 3×3 kernels.
- **Eq. (4.7a)** Sobel `Gx = [f(x+1,y−1) + 2f(x+1,y) + f(x+1,y+1)] − [f(x−1,y−1) + 2f(x−1,y) + f(x−1,y+1)]`; **Eq. (4.7b)** `Gy` = same along columns — Fig 4.2(b) kernels `[-1 -2 -1; 0 0 0; 1 2 1]` and its transpose (correlation form). MATLAB `fspecial('sobel') = [1 2 1; 0 0 0; -1 -2 -1]` = −(Fig 4.2(b) left); sign is irrelevant for the magnitude.
- **Eq. (4.8a/b)** Prewitt: same with weights 1 1 1 (Fig 4.2(c)). All kernels sum to zero (flat regions → 0).
- Edge decision: `|∇f| > T` (T is the sensitivity; noise trade-off [121]); Sobel and Prewitt are isotropic; Sobel's centre weight 2 smooths → preferred [48]. Fig 4.3 (p. 63): Sobel vs Prewitt, both `T = 0.05`, on the two-floe crop Fig 4.3(a).
- Not in the text but in MATLAB's `edge`: gradient kernels are scaled (`/8` Sobel, `/6` Prewitt → true derivative estimates on the [0,1] image), `'replicate'` padding, the automatic threshold `T = sqrt(4·mean(b))` (Pratt p. 514), and a **thinning** step (see §2 notes) — the book's T = 0.05 is meaningful only with these conventions.

### 4.1.2 Laplacian (pp. 63–66)
- **Eq. (4.9)** `∇²f = ∂²f/∂x² + ∂²f/∂y²` — Laplacian.
- **Eq. (4.10)** `∂²f/∂x² ≈ f(x+2,y) − 2f(x+1,y) + f(x,y)` — differencing Eq. 4.6a (centred at x+1).
- **Eq. (4.11)** `∂²f/∂x² ≈ f(x+1,y) + f(x−1,y) − 2f(x,y)`; **Eq. (4.12)** likewise in y — re-centred second differences.
- **Eq. (4.13)** `∇²f = f(x−1,y) + f(x+1,y) + f(x,y−1) + f(x,y+1) − 4f(x,y)` — Fig 4.4(a) kernel `[0 1 0; 1 -4 1; 0 1 0]`; Fig 4.4(b) 8-neighbour kernel `[1 1 1; 1 -8 1; 1 1 1]` (= `fspecial('laplacian',1)·2`… not exactly: `fspecial('laplacian',α)` gives `[α, 1−α, α; 1−α, −4, 1−α; …]/(α+1)`; the book kernels are the α = 0 form and the unscaled 8-neighbour form — implement both literally).
- Zero-crossing detection; simple 3×3 max/min-difference rule [121]; Laplacian is noise-sensitive → smooth first with a Gaussian.
- **Eq. (4.14)** `Gσ(x,y) = exp(−(x²+y²)/(2σ²)) / (2πσ²)` — Gaussian kernel; truncated at 3σ (99 %); Fig 4.5(a) 5×5, σ = 1 (= `fspecial('gaussian',5,1)`, i.e. normalised to unit sum).
- **Eq. (4.15)** `∇²Gσ = (x² + y² − 2σ²)/(2πσ⁶) · exp(−(x²+y²)/(2σ²))` — Laplacian of Gaussian; Fig 4.5(b) 5×5 σ = 1 (= `fspecial('log',5,1)`: Gaussian normalised to sum 1, multiplied by `(x²+y²−2σ²)/σ⁴`, then mean-subtracted so the kernel sums to zero). Alternative: Gaussian ∗ Laplacian kernel [48].
- Fig 4.6 (p. 66): LoG edge detection of Fig 4.3(a), **13×13 kernel, σ = 2, T = 0.005** = `edge(crop,'log',0.005,2)` (MATLAB's default size `2·ceil(3σ)+1 = 13`). No `.m` file → text-only algorithm (port MATLAB's readable `'log'` branch: zero-crossings of the LoG response where the jump `|b(p) − b(q)|` across the crossing exceeds T; exact-zero pixels handled with `2T`).

### 4.2 Morphological edge detection — intro (pp. 66–67)
- Morphology = set-theoretic shape analysis; structuring element (SE) = small 0/1 matrix with an origin (here always the geometric centre, flat, symmetric, unit height).
- Fig 4.7 SEs: (a) 3×3 square, (b) 3×5 rectangle, (c) "disk with 5-pixel radius" printed as the **9×9, 69-px** matrix = MATLAB `strel('disk',5)` (n = 4 approximation, **not** a Euclidean disk, which would be 11×11/81 px), (d) diamond 5 = `strel('diamond',5)` 11×11.
- Non-flat SEs out of scope.

### 4.2.1 Erosion and dilation (pp. 67–71)
- **Eq. (4.16)** `A ⊖ B = {z | (B)z ⊆ A}` — binary erosion; **Eq. (4.17)** `(B)z = {b + z | b ∈ B}` — translation (= `setops.translate`).
- **Eq. (4.18)** `A ⊕ B = {z | (B̂)z ∩ A ≠ ∅}` — binary dilation with the **reflected** SE; **Eq. (4.19)** `B̂ = {w | −w ∈ B}` (= `setops.reflect`).
- Fig 4.8 (p. 70, from DIPUM [49]): 11×15 rectangle image, cross SE, erosion result (3 rows → 1 row, 7 cols → 5) and dilation result (5 rows / 9 cols with clipped corners) — ideal unit-test fixtures (`synth` constants).
- Fig 4.9 (p. 71): binarised Fig 4.3(a) (`im2bw(crop, graythresh(crop))`), erosion, dilation with **r = 15** disk.
- **Eq. (4.20)** `[f ⊖ b](x,y) = min_{(s,t)∈b} f(x+s, y+t)` — grayscale erosion (flat SE); **Eq. (4.21)** `[f ⊕ b](x,y) = max_{(s,t)∈b} f(x−s, y−t)` — grayscale dilation (reflected SE).
- Fig 4.10 (p. 71): grayscale erosion/dilation of Fig 4.3(a), r = 15.
- Border rule (MATLAB, not stated in the text): out-of-image pixels count as 1/+∞ for erosion and 0/−∞ for dilation (verified: padding with 1s reproduces `imerode` exactly).

### 4.2.2 Morphological closing and opening (pp. 71–73)
- **Eq. (4.22)** `A • B = (A ⊕ B) ⊖ B` — closing (fills dark details smaller than B; Fig 4.11 1-D "push down from above").
- **Eq. (4.23)** `A ∘ B = (A ⊖ B) ⊕ B` — opening (removes bright details smaller than B; Fig 4.12 1-D "push up from below").
- Text only (no `.m`); needed by Ch5/Ch7 (`imopen`, `imclose`) → `core.morphology.imopen/imclose`.

### 4.2.3 Morphological reconstruction (pp. 73–77)
- **Eq. (4.24)** `F ⊆ G` — marker inside mask (binary, dilation-based).
- **Eq. (4.25)** `D_G^(1)(F) = (F ⊕ B) ∩ G` — geodesic dilation of size 1; **Eq. (4.26)** `D_G^(n) = D_G^(1)[D_G^(n−1)]`, `D^(0) = F`.
- **Eq. (4.27)** `X_k = (X_{k−1} ⊕ B) ∩ G`, stop when `X_k = X_{k−1}`; `R_G^D(F) = X_k` — reconstruction by dilation.
- **Eq. (4.28)** `E_G^(1)(F) = (F ⊖ B) ∪ G`, `G ⊆ F`; **Eq. (4.29)** size-n recursion; **Eq. (4.30)** `X_k = (X_{k−1} ⊖ B) ∪ G` → `R_G^E(F)` — reconstruction by erosion.
- **Eq. (4.31)** `f ≤ g`; **Eq. (4.32)** `D_g^(1)(f) = (f ⊕ b) ∧ g` (pointwise min); **Eq. (4.33)** recursion; **Eq. (4.34)** `X_k = (X_{k−1} ⊕ b) ∧ g` → `R_g^D(f)` — grayscale reconstruction by dilation (extracts mask peaks marked by f; Fig 4.13 1-D).
- **Eq. (4.35)** `f ≥ g`; **Eq. (4.36)** `E_g^(1)(f) = (f ⊖ b) ∨ g` (pointwise max); **Eq. (4.37)** recursion; **Eq. (4.38)** `X_k = (X_{k−1} ⊖ b) ∨ g` → `R_g^E(f)` — grayscale reconstruction by erosion (valleys; Fig 4.14 1-D).
- Text only; B defines connectivity (MATLAB `imreconstruct(marker, mask, conn)` uses 8-conn = 3×3 SE by default). Consumed by Ch5 (`imimposemin`, `imreconstruct` in watershed marker construction) and Ch7.

### 4.2.4 Morphological gradient (pp. 77–79)
- **Eq. (4.39)** `ρ = (A ⊕ B) − (A ⊖ B)` — basic (Beucher) gradient; ≈ |∇| for small B [12].
- **Eq. (4.40)** `ρ_int = A − (A ⊖ B)` — internal gradient (edges inside objects).
- **Eq. (4.41)** `ρ_ext = (A ⊕ B) − A` — external gradient (edges outside).
- **Eq. (4.42)** `ρ_int + ρ_ext = ρ` — half-gradients are thinner; choice depends on the objects [126].
- Fig 4.15 (p. 79): binary gradients of Fig 4.3(a), r = 15 (caption typo "157-pixel-radius"); Fig 4.16: grayscale gradients, r = 15. Code: `morphology.m` (but with r = 7 and the full `test.jpg`).

### 4.3 Experimental results and discussion (pp. 78–82)
- (a) Sobel ≈ Prewitt; (b) second derivative noise-sensitive; (c) grayscale morphological gradient is "derivative-like" → only Sobel and the **binary internal gradient** are compared further.
- Fig 4.17 (p. 80): unshipped sea-ice image; (b) Sobel T = 0.05; (c) internal gradient, **r = 5** disk. Isolated floes: both fine; touching floes: both fail.
- Fig 4.18 (p. 81): crop of connected floes; Sobel finds weak (non-closed) edges between floes; internal gradient gives closed edges but loses the weak ones.
- Fig 4.19 (p. 81): Sobel T = 0.05 vs **T = 0.03** — more weak edges, more noise, more non-closed edges.
- Fig 4.20 (p. 82): internal gradient r = 5 (thin edges, floes stay connected) vs **r = 16** (thick edges break weak connections) — not general; larger SE shrinks floes.
- Conclusion: neither method separates tightly connected floes → Ch5 watershed / Ch6 GVF.

### MATLAB internals that the port must reproduce (read from R2025a `toolbox/images/images/edge.m`, `fspecial.m`, `+images/+internal/+coder/+strel/StructuringElementHelper.m`)
- `edge(a,'sobel'|'prewitt', T, 'both', 'thinning')`: `op = fspecial('sobel')/8` (Prewitt `/6`); `bx = imfilter(a, op', 'replicate')` (column derivative, vertical edges; = 4th output `gv`), `by = imfilter(a, op, 'replicate')` (= `gh`); `b = kx·bx² + ky·by²` (kx = ky = 1 for `'both'`; `'horizontal'` → kx = 0, `'vertical'` → ky = 0); `cutoff = T²` if T given, else `cutoff = 4·mean(b)` and returned `thresh = sqrt(cutoff)`; without thinning `e = b > cutoff`. **Thinning** (compiled `images.internal.builtins.computeEdges(b,bx,by,kx,ky,int8([0 0 0 0]),100·eps,cutoff)`), reproduced with 0 px difference by:
  ```
  bx = |bx|; by = |by|; pad b by 1 px with 'replicate';  eps' = 100*eps
  e = b > cutoff & ( (bx >= by − eps' & b(r,c−1) <= b(r,c) & b(r,c) > b(r,c+1))
                   | (by >= bx − eps' & b(r−1,c) <= b(r,c) & b(r,c) > b(r+1,c)) )
  ```
  (both branches may fire; ties: `<=` on the left/up neighbour, strict `>` on the right/down neighbour — a 1-px-wide ridge keeps its first pixel; the zero-border variant of old M-code releases differs only at the border).
- `edge(a,'roberts', T)`: masks `[1 0; 0 −1]/2`, `[0 1; −1 0]/2`, `scale = 6`, offsets `[−1 1 1 −1]` (thinning compares diagonal neighbours). Not in the book — optional; include only if cheap (same thinning routine with offset arguments).
- `edge(a,'log', T, σ)` (readable M-code): `fsize = 2·ceil(3σ)+1`, `op = fspecial('log', fsize, σ)`, `op −= mean(op)`, `b = imfilter(a, op, 'replicate')`, `T` default `0.75·mean(|b|)`; edge = negative pixel of a sign change in the interior (`rr = 2:m−1`, `cc = 2:n−1`): `b(r,c) < 0 & b(r,c+1) > 0 & |b(r,c) − b(r,c+1)| > T`, and the `[+ −]`, vertical `[− +]ᵀ`, `[+ −]ᵀ` variants; pixels with `b == 0` are edges if `b(r−1,c)` and `b(r+1,c)` (or left/right) have opposite signs and `|difference| > 2T`. `'zerocross'` = same with a user kernel `H`.
- `fspecial`: `'sobel' = [1 2 1; 0 0 0; −1 −2 −1]`, `'prewitt' = [1 1 1; 0 0 0; −1 −1 −1]`, `'laplacian'(α=0.2) = [α 1−α α; 1−α −4 1−α; α 1−α α]/(α+1)`, `'gaussian'(hsize=[3 3], σ=0.5)`: `exp(−(x²+y²)/(2σ²))` on the centred grid, `/sum`; `'log'(hsize=[5 5], σ=0.5)`: `h = gaussian/sum`, `h1 = h·(x²+y²−2σ²)/σ⁴`, `h = h1 − mean(h1)`; `'average'(hsize=[3 3])` = `ones/prod`; `'disk'(r=5)` = area-weighted pillbox.
- `strel('disk', r, n=4)` (r ≥ 3; r < 3 → exact Euclidean `x²+y² ≤ r²`): `v = [1 0; 1 1; 0 1; −1 1]`, `θ = π/(2n)`, `k = 2r/(cot θ + 1/sin θ)`, `rp_q = floor(k/‖v_q‖)`; periodic-line SEs `{j·v_q : j = −rp_q..rp_q}`; dilate them together; `max_horiz_radius` = largest row offset of the result; `len = 2(r − max_horiz_radius − 1) + 1`; if `len ≥ 3` also dilate with horizontal and vertical lines of length `len` (`intline`, symmetric about the origin). r = 7 → k = 2.785, rp = [2 1 2 1] → 9×9, then len = 5 → **13×13** (Fig 4.7(c)-style octagon). `'diamond'(M)` = `|x|+|y| ≤ M`; `'square'(w)`, `'rectangle'([m n])`, `'line'(len, deg)`, `'octagon'`, `'periodicline'(p, v)`, arbitrary `strel(nhood)`. `imerode`/`imdilate` with a decomposed SE give the same result as with `getnhood(se)` (Minkowski-sum identity), so the port may use the full neighbourhood (or the decomposition for speed).
- `imerode(I, SE)`: min over the SE (binary: all-ones test), out-of-image = 1 / +∞; `imdilate`: max over the **reflected** SE, out-of-image = 0 / −∞. `imreconstruct(marker, mask)` = Eq. 4.34 with 8-connectivity (marker clipped to `min(marker, mask)` is *not* done — MATLAB requires `marker ≤ mask`).

## 7. Risks & questions

1. **Compiled thinning**: `edge`'s Sobel/Prewitt thinning is a builtin; the rule above was reverse-engineered (0 px on 12.25 Mpx
   + a random field), and exact-tie behaviour (`100·eps`, `<=` vs `>`) is only probed statistically → `compat.mat` must include
   constructed ties (equal neighbouring magnitudes, `|bx| == |by|`) before the label `exact` is final. Roberts' offset variant is
   unverified until `compat.mat` exists.
2. `double(im)/256` (not `im2double`) — port literally; the library `edge` takes any float image, but the book's T = 0.05 and the
   auto threshold change if `/255` is used (document in the script and notebook).
3. **Parameter mismatch text vs code**: text figures use r = 15 (Figs 4.9–4.16), r = 5 (4.17(c), 4.18(c), 4.20(a)), r = 16
   (4.20(b)); the script uses r = 7; Fig 4.15 caption says "157". The port exposes `--radius`, default 7 = script.
4. **Crop semantics**: Figs 4.3–4.16 are "of Figure 4.3(a)" = a crop of `test.jpg`; crop-then-process (chosen) vs
   process-then-crop differ within 15 px of the crop border for r = 15 and 1 px for Sobel. Crop rectangle from template matching
   (NCC 0.998) may be off by 1–2 px; verification refines by maximising NCC at full resolution.
5. **Unshipped image for §4.3** (Figs 4.17–4.20): only qualitative reproduction; the connected-floe crop must be chosen on
   `test.jpg` by the porter and stated as such in the notebook.
6. **Approximate disk**: `skimage.morphology.disk(r)` / `cv2.getStructuringElement(MORPH_ELLIPSE)` are Euclidean and differ from
   MATLAB's n = 4 decomposition (r = 7: 13×13/157 px vs 15×15/149 px); the port must implement the decomposition; `'dis'` prefix
   matching must be supported (MATLAB accepts unambiguous prefixes).
7. **Reflection convention** of `imdilate` (Eq. 4.18/4.21) is invisible for symmetric disks; scipy `grey_dilation` and
   `binary_dilation` reflect the structure, OpenCV `dilate` does not → whichever backend is used, the asymmetric-SE compat case
   decides; keep one backend to avoid mixed conventions.
8. **Speed**: 4290×2856 grayscale erosion with a 29×29 (697-px) footprint in `scipy.ndimage` may take tens of seconds; the disk
   decomposition (`decompose=True`, sequential erosions by 4 periodic lines + 2 lines) or OpenCV (`BORDER_CONSTANT` with
   dtype max/min) keeps the notebook fast — both must be tested for exactness against the full-footprint result.
9. **Integer arithmetic**: `im − X` etc. are uint8 saturating in MATLAB but non-negative here; the generic
   `morphological_gradient` must compute in a wider type (an arbitrary A−B would saturate at 0 in MATLAB — reproduce that when
   `dtype` is uint8: `max(A − B, 0)`); binary `I − J` is double 0/1 in MATLAB — the port returns uint8 0/1 (documented).
10. **Eq. 4.3 as printed** is `arctan(Gx/Gy)` while `Gx = ∂f/∂x` with book `x` = row: the direction convention is ambiguous
    (angle from the x-axis = row axis?). Implement `gradient_direction(Gx, Gy, convention='book'|'math')` and state the choice;
    no figure depends on it.
11. **Sign/scale of the printed kernels vs MATLAB**: Fig 4.2(b) left kernel = −`fspecial('sobel')`, and `edge` divides by 8 (Prewitt
    6); the book-equation `gradient_operator` returns unscaled book-sign gradients; the docstring must state
    `Gx_book = −8·by_matlab`, `Gy_book = −8·bx_matlab`.
12. **LoG**: Fig 4.5(b) equals `fspecial('log')` (unit-sum Gaussian, mean-subtracted), not Eq. 4.15 sampled (which has the
    `1/(2πσ⁶)` factor and does not sum to zero); MATLAB's LoG threshold is applied to the **jump across the zero crossing**
    (`|b(p) − b(q)| > T`), not to `|b|` — the notebook must say so because the text only says "threshold T = 0.005". The
    `'log'` method also re-subtracts the kernel mean (`op − mean(op)`), a no-op for `fspecial('log')` up to 1e-17.
13. `edge` converts non-float inputs internally (`im2single` for `log`/`canny` paths; Sobel/Prewitt builtins accept uint8
    directly with a different scaling) — the port accepts float only and raises otherwise, since both scripts pass double.
14. `bwareaopen`, `medfilt2`, `conv2(..., msk)` are commented out in `derivative.m`; they are optional flags, but `conv2` default
    `'full'` changes the size (4294×2860) — keep MATLAB semantics if the flag is used.
15. Later-chapter dependencies to confirm in their analyses: ch5 uses `strel('disk')`, `imerode/imdilate`, `imreconstruct`,
    `imimposemin`, `imregionalmin`, `bwdist`, `watershed`; ch6 GVF code uses `fspecial('gaussian')`/`edge` for the edge map;
    ch7 uses `imopen/imclose/bwmorph`. The primitives here are designed with those signatures in mind (`conn` arguments,
    dtype preservation, bool in → bool out).
16. `outputs/tmp_p{4,12,20,21,22,23}.png` were rendered during analysis (git-ignored `outputs/`); they can be deleted.
