### Chapter 9 inputs with **no** substitute (generated synthetically instead)
Three of chapter 9's four external inputs are model-ice video from the HSVA/DYPIC towing-tank campaign and are neither shipped with the book nor published anywhere; the fourth is the Fig. 9.1 tank strip. There is no Tier-2 (public imagery) or Tier-4 (manual download) path for any of them, so `seaice.core.synth` generates stand-ins whose sole purpose is to exercise every code path. **No book number is computed from synthetic data** — every printed value that depends on these inputs stays `unverified` in `reports/ch09_verification.md`.

| missing input | read by | stand-in |
|---|---|---|
| `04100_analyse.jpg` (Fig. 9.1 tank strip, printed 442×87) | `block_threshold.m` | `core.synth.model_ice_tank` |
| `dypic_05100_cam1_top.avi` | `movie_otsu.m`, `movie_kmeans.m` | `core.synth.model_ice_tank_video` |
| `05100.avi` (already-segmented frames) | `movie_floe.m` | `core.synth.segmented_floe_video` |
