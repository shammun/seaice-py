## 1. Concepts (what the chapter teaches, in our words)

- Ice is brighter than water, so the ice mask is a threshold of the gray image: `g = 1 if f > T else 0` — Eq. (3.1),
  **strict `>`** (= MATLAB `im2bw`). The chapter's output is a binary/k-level mask plus the **ice concentration**
  `IC = #ice / (M N)`, consumed by Ch4–Ch9.
- Global vs local (variable) thresholding (§3.1); a bimodal histogram puts `T` in the valley (Fig. 3.1/3.2), but noisy
  histograms and image-to-image variability call for an automatic `T`.
- Otsu (§3.1.1.1): from the normalised histogram `p_i = n_i/n` (Eqs. 3.2–3.3) build class probabilities `P0(t)`,
  `P1(t)` (3.4–3.5), class means `m0`, `m1` (3.6–3.7), cumulative mean `m(t)` (3.8) and global mean `mG` (3.9);
  between-class variance `σB²(t) = P0 P1 (m0 − m1)² = (mG P0 − m(t))² / (P0 (1 − P0))` (3.16); within-class `σW²`
  (3.15); global `σG²` (3.17); `σW² + σB² = σG²` (3.18).
- The three criteria `λ = σB²/σW²`, `κ = σG²/σW²`, `η = σB²/σG²` (3.14) are monotone in each other (3.19); the one
  maximised is `η(t)` (3.20); `t* = argmax σB²(t)` by exhaustive search over integer `t` (3.21), **ties averaged**;
  `0 ≤ η(t*) ≤ 1` is the *separability* (3.22): 0 for a constant image, 1 for a two-valued `{0, L−1}` image.
- MATLAB `[level, em] = graythresh(I)` returns exactly `t*/255` and `em = η(t*)`.
- Local thresholding (§3.1.2, Fig. 3.4): under uneven illumination global Otsu fails; split into `n_r × n_c` blocks,
  Otsu per block, `IC = Σ n_block / (r c)`. Same algorithm as ch9 `block_threshold.m`.
- Multithresholding (§3.1.3): `k − 1` thresholds give `k` classes (3.23, = `imquantize`); maximise the multi-class
  `σB² = Σ_j P_j (m_j − mG)²` (3.24–3.27) exhaustively; separability `η = σB²/σG²` (3.28) = `multithresh`'s `metric`.
  MATLAB is exhaustive only for `N ≤ 2`; `N ≥ 3` uses `fminsearch` (local).
- Clustering (§3.2): distance measures — Euclidean (3.29), squared Euclidean (3.30), max-norm (3.31), city-block
  (3.32), cosine (3.33, printed as a *similarity*), Mahalanobis (3.34); hierarchical vs partition clustering.
- K-means (§3.2.2): minimise `J = Σ_i Σ_j ‖x_j − c_i‖²` (3.35) by alternating nearest-centroid assignment (3.36) and
  mean update (3.37) until the centroids stop changing; converges to a local minimum; sensitive to `k`, to the initial
  centroids (Fig. 3.6) and to outliers (Fig. 3.8).
- The authors' `kmeans.m` is a **deterministic 1-D k-means on the gray histogram** with equal-division initial
  centroids `mu = (1:k)·m/(k+1)` (§3.3 "equal division points") — not the Statistics Toolbox function it shadows.
- §3.3 results: on uniformly bright ice (images 1, 2) Otsu ≈ k-means (both minimise within-class variance); on image 3
  Otsu (72.63 %) misses dark ice (brash/slush/submerged) that k-means (96.50 %) captures; three groups via multi-Otsu
  (`N = 2`) or k-means (`k = 3`) separate bright ice / dark ice / water (Tables 3.2–3.3). Both methods force ≥ 2
  classes → fail at IC = 0 % or 100 %.

## 4. MATLAB→Python lessons learned (new pitfalls; each is a row in `function_map.md`)

1. **`graythresh` is not `skimage.filters.threshold_otsu`**: MATLAB does `im2uint8` → 256-bin `imhist` → `otsuthresh`,
   which **averages tied maximisers** (`mean(find(σB² == max))`) so `level·255` can be a half-integer (104.5); the
   second output `em` is the book's `η(t*)`. `im2bw` then compares in **double** (`uint8([104 105 106]) > 104.5 =
   [0 1 1]`, confirmed in R2025a) — keep levels float end-to-end, never round them. `255·(i/255) == i` for every `i`.
2. **`graythresh` does not convert RGB** (it histograms all three planes), `im2bw` does (`rgb2gray`). Always pass
   `rgb2gray_matlab(rgb)` explicitly.
3. **`multithresh`'s `getpdf` works in single precision twice**: `single(A − minA)/single(maxA − minA)` *and* the
   `x·255` product inside the `grayto8` builtin — a float64 product misplaced one bin (212.4999949 → single 212.5 →
   bin 213) and moved the Eq. 3.28 metric by 1.1e-4. Emulate both in float32. Output thresholds come back in the
   **input class** (`map2OriginalScale`, MATLAB rounding).
4. **`multithresh` `N ≥ 3` is `fminsearch`** (Nelder–Mead, `TolX = 1`) — a local search that can return a worse split
   than the exhaustive Eq. 3.27 (1.jpg: 50,101,165 vs the port's 49,86,160 with larger σB²) or even its initial guess
   with `metric = −Inf`. Label `reimplemented`, never `exact`. `t1 = 0` is a legitimate candidate for every `N`
   (as in `otsuthresh` and the `N = 2` matrix) although the book prints `0 < t1`.
5. **`multithresh` degenerate inputs**: `getDegenerateThresholds` only when `numel(unique(A)) ≤ N` (constant uint8 →
   `[1 77]` for `N = 2`, `zeros(4,4,'uint8')` → `[0 1]`, `[0 255]` `N = 3` → `[0 1 255]`, `[100 255]` → `[1 100 255]`);
   the `noConvergence` path returns *more* than `N` values for `N < 3`. int16 input saturates in `single(A − minA)`
   (`approx`, not a book case).
6. **`imquantize(A, levels)` = `1 + Σ_i (A > level_i)`** (classes `1..N+1`, strict `>` like Eq. 3.23); comparison in
   double so uint8 thresholds and float images mix.
7. **A script can shadow a toolbox function**: `ch3/kmeans.m` is the authors' own algorithm, not a wrapper for the
   Statistics Toolbox `kmeans` that ch6/ch7/ch9 call. Check every chapter folder for files named like toolbox
   functions before mapping a call; never `addpath` a chapter folder globally when generating references.
8. **`kmeans.m` units bug** (lines 64–70): the mask compares the *unshifted* image with centroids in
   `ima − min + 1` units, so every class boundary is `min − 1` levels too low (20 on test.jpg). **Every k-means number
   in the book needs `shift_bug=True`**; the library default applies Eqs. 3.36–3.37 consistently. An empty cluster makes
   MATLAB loop forever (`NaN == NaN` is false) — the port raises.
9. **Stale buffers in loops**: `s(j) = I(p(j))` is never cleared between classes in `Otsu.m`/`kmeans.m`, so a class
   smaller than an earlier one sums stale entries (MATLAB prints a "mean gray level" of 4759.10 on 1.jpg). Harmless in
   the book only because test.jpg's class sizes increase. `sum(uint8 vector)` returns **double** (no saturation) — the
   emulation must sum in float; `find` fills the buffer in column-major order.
10. **`num2str(x)` scalar rule**: integers print as `%d`; otherwise `%.{n}g` with `n = max(floor(log10|x|) + 5, 5)`
    significant digits (`73.8472`, `86.496`, `0.12346`, `1234.5679`). Figure titles built with `num2str` must use it
    to be byte-identical (Fig. 3.4(c) `IC=86.496%`).
11. **1-based bin index used as intensity** (`separability.m`: `i = 1..256`): shift-invariant quantities (σB², σG², η)
    come out right but the class split is off by one — the script's `eta` is `η(k − 1)` while its mask is `I > k`.
    Port the quirk literally in the script wrapper and expose the book convention separately.
12. **`colormap('default')` after `imshow(double)`** renders the mask in parula in MATLAB; the book shows gray. Display
    only — save gray and mention it.
13. **Pre-checks are not references**: the analysis's "independent multi-Otsu" pre-check said 79 for 1.jpg; MATLAB says
    78. Every number in a report must come from the MATLAB run, not from an approximate cross-check.
14. **Patch script copies, not MATLAB_ROOT**: for hard-coded `imread('test.jpg')` / `k = 3`, copy the `.m` verbatim into
    the scratch cwd under a non-shadowing name, patch only the literals (and add counters such as `n_iter`), run with
    cwd = scratch. Substitutes for unshipped inputs are placed in scratch under the original name so MATLAB and Python
    decode the same bytes (JPEG q95 4:4:4 for the synthetic ramp).
15. **JPEG decode parity holds at 12 Mpx**: imageio/Pillow = MATLAB `imread` on all three 4290×2856 files (0 px after
    `rgb2gray`), so ch4–ch9 masks derived from `im2bw(I, graythresh(I))` can be compared at 0-px tolerance.
16. **`im2uint8` on uint16 = `round(v/257)`** (`(v + 128)/257` integer), int16 = `(v + 32768)` first; verified for all
    65 536 values. `matlab_compat.im2uint8` still takes the float path (×255) for uint16 — use `threshold._im2uint8_any`
    until it is merged (open item 3).
17. **Inventory watchlist gaps**: `analysis/_matlab_inventory.md` did not list `multithresh`, `imquantize`, `colormap`
    as toolbox calls — extend the watchlist for ch7/ch8 (three-group ice typing uses `multithresh`).
